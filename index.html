Electrical Submittal Compliance Checker

CON 453 · Kill the Grind · Version 1.0 · Panelboard screening prototype

Purpose and scope

Compare a project-specific panelboard requirement against manufacturer product data. The checker flags exact mismatches, missing information, and values below required minimums. It is a rule-based prototype, not an AI model, PDF reader, engineer's approval, or complete submittal package.

Important: The included examples are synthetic teaching data, not verified Schneider Electric products or actual project schedules. Do not use for purchasing, installation, or engineering approvals.

3 · Testing notes for D2

Three built-in synthetic test cases: (1) matching selected equipment should have no mismatches or missing values; (2) a blank model should be flagged as missing; (3) a selected 120/208V panelboard against a 277/480V requirement should be flagged as a mismatch. Record the actual results and screenshots after running each test. The baseline is synthetic, not an actual timed manual workflow.

Logic: exact-match fields must match, numeric ratings must meet or exceed a stated minimum, and required seismic documentation must be supplied. Unknown data never counts as passing. If a project requirement is not entered, the field is shown as “Not assessed,” not assumed to be compliant. The checker does not extract text directly from PDFs, verify citations, distinguish line vs phase voltages beyond the provided labels, or validate UL listings.

Prototype for academic demonstration · Always verify original drawings, specifications, schedules and manufacturer cut sheets.
